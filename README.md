🧮 Simple Calculator – C# Windows Forms App

A basic calculator application built with C# and Windows Forms. This project demonstrates object-oriented programming, event-driven design, and user interface handling in .NET.

---

📦 Features

- Arithmetic Operations:
  - Addition (plus)
  - Subtraction (mines)
  - Multiplication (Multiply)
  - Division (division)

- User Interface:
  - Textboxes for entering two numbers (txtn1, txtn2)
  - Buttons for each operation (btnplus, btnmines, btnMultiply, btndiv)
  - Labels to display the result (lblresult) and operator (lbloperator)

- Event Handling:
  - Each button click triggers the corresponding arithmetic method.
  - MouseDown event (btnall_mouseDown) parses user input into numeric values.
  - Results are displayed dynamically in the form.

---

🛠 Technologies Used

- Language: C#
- Framework: .NET (Windows Forms)
- IDE: Visual Studio

---

🚀 How to Run

1. Clone or download the repository.  
2. Open the solution in Visual Studio.  
3. Build and run the project.  
4. Enter two numbers in the textboxes.  
5. Click an operation button to see the result.
